# Paper workspace

- `realm2026/` is the active archival short-paper target. It uses the official
  ACL review style and contains the current submission plan.
- `icaif2026/` preserves the earlier ACM manuscript, development-gate analysis,
  reviewer notes, and decision memo. It is research provenance, not the active
  submission format.

Generated LaTeX files and rendered page images belong in each paper's ignored
`build/` directory. Source figures, bibliography files, frozen analysis
artifacts, and manuscript source remain tracked.
