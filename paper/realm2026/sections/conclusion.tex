\section{Conclusion}

The prospectively frozen corrective study matched answer and resource contracts
and verified retrieval on every ReAct row. Static still held a macro advantage
whose 95\% interval excluded zero, with 21 versus five unique exact successes.
The earlier selector failure is therefore best understood as a resource-
allocation failure, not merely a poor routing threshold. Routing cannot
manufacture value from an expert that lacks \emph{measured} complementary
accuracy under the deployed evaluation contract. Auditing contract fairness
and expert value should precede difficulty modeling, threshold tuning, and
confirmatory testing.
