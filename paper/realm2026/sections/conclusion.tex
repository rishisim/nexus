\section{Conclusion}

This work treated agentic financial QA as a resource-allocation hypothesis and
applied a documented development gate, which rejected the current selector.
The original study placed Static above bounded ReAct, but a trace audit exposed
answer and context asymmetries. A fresh, prospectively frozen comparison matched
those contracts and verified retrieval on every ReAct row; Static still held a
macro advantage whose frozen 95\% interval excluded zero and 21 versus five
unique exact successes.
The defensible lesson is conditional: routing cannot manufacture value from an
expert that lacks \emph{measured} complementary accuracy under the deployed
evaluation contract. Auditing that contract and expert value should precede
difficulty modeling, threshold tuning, and confirmatory testing.
