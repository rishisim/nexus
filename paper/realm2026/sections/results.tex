\paragraph{Corrective study.}
Table~\ref{tab:corrective-result} is the narrative centerpiece. All 150 ReAct
rows passed the retrieval-first manipulation check. The paired stratified
ReAct-minus-Static macro estimate was $-0.0849$ (95\% CI
$[-0.1467,-0.0252]$). Exact complementarity was 21 Static-only versus five
ReAct-only cases (McNemar $p=0.00249$); the oracle union improves over
always-Static exact accuracy by only 3.3 points. The difference was clearest on
FinQA ($-0.160$), while dataset-level intervals included zero for TAT-QA and
ConvFinQA. ReAct averaged 1.04 more model calls and 1.02 additional seconds per
item. Static averaged 2.87 retrievals versus ReAct's 1.04, so the iterative arm
used fewer input tokens and dollars despite its additional calls. These are
development results, not a final-partition estimate.

\paragraph{Pilot routing evidence.}
The earlier Gemini study used a separate sample and unequal method contracts.
Its best primary macro was CoT/PoT at 0.4323; Static Nexus scored 0.4304, ReAct
0.2993, and Selective Nexus 0.3675. ReAct was 0.131 below Static Nexus
(ReAct-minus-Static CI $[-0.207,-0.056]$) and cost more. The fallback selector
was 0.0648 below CoT/PoT while also costing more, so it missed the documented
quality--cost criterion. We retain this as the motivating observation and
supporting evidence, not a benchmark ranking or the main causal comparison.

\paragraph{Confirmatory evaluation.}
The recorded conditional required Selective Nexus either to improve quality
while reducing cost or to stay within one absolute point of the best macro with
at least 30\% lower cost. It does neither, so we did not execute the protected
final partition and report no confirmatory or semantic FinDER results.
