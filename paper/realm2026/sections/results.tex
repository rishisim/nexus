\paragraph{Original quality--cost result.}
CoT/PoT has the highest observed macro and costs less than Static Nexus, ReAct,
and Selective Nexus, although its paired difference from Direct is uncertain
(95\% stratified bootstrap CI: $[-0.035,0.072]$). ReAct is 0.131 below Static
Nexus (ReAct-minus-Static CI: $[-0.207,-0.056]$) and costs more. Selective Nexus
is 0.0648 below CoT/PoT while also costing more, so it fails that gate
regardless of whether that development difference is treated inferentially.

\paragraph{Corrective study.}
In fresh harmonized v2, all 150 ReAct rows passed the retrieval-first
manipulation check. Static scored 0.3421 versus 0.2572; the paired stratified
ReAct-minus-Static estimate was $-0.0849$ (95\% CI
$[-0.1467,-0.0252]$). Exact complementarity was 21 Static-only, five
ReAct-only, 23 both-correct, and 101 both-wrong (McNemar $p=0.00249$). The
difference was clearest on FinQA ($-0.160$); dataset-level intervals included
zero for TAT-QA and ConvFinQA. ReAct averaged 2.04 calls and 1.02 additional
seconds per item. Static averaged 2.87 retrievals versus ReAct's 1.04, so ReAct
used fewer tokens and dollars. This is development evidence, not a
final-partition estimate.

\paragraph{Go/no-go decision.}
The recorded conditional required Selective Nexus either to improve quality
while reducing cost or to stay within one absolute point of the best macro with
at least 30\% lower cost. It does neither. The 900-example final partition
therefore remains unexecuted; there is no confirmatory or semantic FinDER result.
