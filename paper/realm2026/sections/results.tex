\paragraph{Capability changes the average ordering.}
Table~\ref{tab:capability-result} is the narrative centerpiece. Static's macro
advantage excludes zero for control and Luna. Terra instead reaches parity,
with a small nonsignificant ReAct edge. The ReAct-minus-Static interaction is
$0.079$ for Terra minus control (95\% CI $[0.028,0.133]$) and $0.065$ for Terra
minus Luna ($[0.018,0.117]$); Luna minus control is $0.014$
($[-0.043,0.071]$). Thus the earlier ReAct deficit is not invariant to model
tier.

\paragraph{Complementarity remains negligible.}
The capability boundary does not yield routing opportunity. ReAct is uniquely
exact on only two control, one Luna, and two Terra items. Oracle gain over the
better branch is therefore 1.3, 0.7, and 0.7 points. McNemar tests favor Static
for control ($p=0.0074$) and Luna ($p=0.0215$), while Terra's three discordant
items provide no directional evidence ($p=1.0$). No router is fit to these
outcomes.

\paragraph{Efficiency.}
Static uses one call per item; ReAct averages 2.31, 2.27, and 2.16 calls for
control, Luna, and Terra. In the same order, ReAct takes 2.6, 2.4, and 2.1
times as long and costs 1.29, 1.29, and 1.14 times as much. It is therefore
neither cheaper nor faster in the main study.

\paragraph{Supporting evidence.}
On a separate harmonized-v2 sample, Static scored 0.342 versus ReAct's 0.257
($\Delta=-0.085$, 95\% CI $[-0.147,-0.025]$), with 21 Static-only versus five
ReAct-only exact successes and 3.3 points of oracle headroom. The earlier pilot
selector likewise missed its documented quality--cost criterion. Contract
asymmetries make the pilot noncentral, but neither supporting study contradicts
the main complementarity diagnosis.
