The aggregate matrices hide no dataset with substantial exact complementarity.
In ConvFinQA/FinQA/TAT-QA order, per-dataset B/S/R/N are
3/5/1/41, 0/2/1/47, and 9/6/0/35 for control;
3/2/0/45, 1/1/0/48, and 3/6/1/40 for Luna; and
5/1/0/44, 2/0/1/47, and 14/0/1/35 for Terra.

\paragraph{Capability changes the average ordering.}
Table~\ref{tab:capabilityresult} is the narrative centerpiece. Static's macro
advantage excludes zero for control and Luna. Terra instead reaches parity,
with a small nonsignificant ReAct edge. The ReAct minus Static interaction is
$0.079$ for Terra minus control (95\% CI $[0.028,0.133]$) and $0.065$ for Terra
minus Luna ($[0.018,0.117]$); Luna minus control is $0.014$
($[-0.043,0.071]$). Thus the earlier ReAct deficit is not invariant to model
tier.

\paragraph{Complementarity remains small.}
Neither branch is exactly correct on 123/150 control items, 133/150 Luna
items, and 126/150 Terra items (82.0--88.7\%). Thus low complementarity here
coexists with a near-floor operating point: the systems usually fail together,
rather than partitioning a large set of solvable cases.
Under the actual quality metric, including F1, oracle headroom point estimates
are 1.7, 1.0, and 1.0 points, with paired 95\% upper limits of 3.8, 1.9, and
2.1. These intervals are tighter than exact match intervals because they use
bounded continuous gains for each item rather than binomial uncertainty around
only one or two rare events. Exact headroom point estimates are 1.3, 0.7, and
0.7 points; conditional on the direction of the empirically better arm, exact binomial
95\% upper limits are 4.7, 3.7, and 3.7. Even 4.7 points is an oracle ceiling:
a learned router can recover only part of it and adds selection errors and
cost. Concretely, control has B/S/R/N $=12/13/2/123$: Static gets
$25/150$, the union gets $27/150$, and even perfect routing adds only
$2/150=1.3$ points. McNemar tests favor Static for control ($p=0.0074$) and Luna
($p=0.0215$); Terra shows no directional difference ($p=1.0$). No router is fit
to these outcomes.

\paragraph{Efficiency.}
Static uses one call per item; ReAct averages 2.31, 2.27, and 2.16 calls for
control, Luna, and Terra. In the same order, ReAct takes 2.6, 2.4, and 2.1
times as long and costs 1.29, 1.29, and 1.14 times as much. It is therefore
neither cheaper nor faster in the main study.

\paragraph{Post hoc seed stability.}
Changing only the request seed on the same manifest reproduced Static
advantages for control and Luna; Terra's small difference changed sign but
remained near parity (Static/ReAct: 0.201/0.196). Exact B/S/R/N became
13/12/1/124, 5/13/1/131, and 20/1/0/129; the rare exact oracle benefit cells
were one, one, and zero. Native quality headroom was 1.4, 0.8, and 0.7 points
(95\% upper limits 3.1, 1.8, and 1.4). Individual generations and Terra's point
ordering vary, but the low complementarity diagnosis does not in this single
check on the same sample.

\paragraph{Supporting evidence.}
On a separate harmonized v2 sample, Static scored 0.342 versus ReAct's 0.257
($\Delta=-0.085$, 95\% CI $[-0.147,-0.025]$), with 21 successes unique to Static
versus five unique to ReAct and 3.3 points of oracle headroom. The earlier pilot
selector likewise missed its documented quality and cost criterion. Contract
asymmetries make the pilot noncentral, but neither supporting study contradicts
the main complementarity diagnosis. The provider-free artifact, including the
sanitized paired records behind every matrix, is publicly available at the
tagged repository snapshot.\footnote{\href{https://github.com/rishisim/nexus/tree/realm-emnlp-2026-camera-ready}{Camera-ready repository snapshot}; see \texttt{paper/realm2026/artifact}.}
