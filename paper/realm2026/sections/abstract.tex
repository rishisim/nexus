Iterative language-model agents spend additional inference in the hope of
recovering errors made by simpler readers. We test a necessary precondition for
that trade-off: whether the expensive expert is actually complementary. In a
preregistered, controlled-evidence development study spanning five financial-QA
datasets, bounded ReAct was both less accurate and more costly than structured
one-call reasoning. Only 10 of 200 objectively scored routing examples were
ReAct-only successes, versus 42 Static-only successes. This sparse benefit class
triggered our prespecified rule fallback instead of a learned selector. The
resulting policy escalated 70\% of cases, increasing mean cost while reducing
exact accuracy from 0.395 for the static path to 0.295. We therefore honored the
registered stop and left a disjoint 900-example final manifest unopened. The
result is deliberately development-only, but it exposes a methodological trap:
difficulty routing cannot create value when the proposed expert rarely supplies
unique correct answers. Agent-routing studies should establish expert
complementarity before optimizing when to escalate.
