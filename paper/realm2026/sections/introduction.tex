\section{Introduction}

Financial QA requires evidence selection, arithmetic, and careful handling of
entities, periods, signs, and units. Iterative language-model agents appear well
suited to these demands: they can search, inspect evidence, and revise an answer.
Each extra step, however, consumes tokens and latency and can introduce a new
retrieval, arithmetic, or formatting error. The relevant deployment question is
therefore not simply whether an agent can answer, but when its additional
computation is worth paying for.

We study a necessary precondition for selective agency: \emph{expert
complementarity}. A router can improve an accuracy--cost frontier only when its
expensive branch supplies enough unique correct answers. We isolate this issue
under controlled evidence. Every system receives the same leakage-audited
benchmark corpus and tools, so differences reflect orchestration rather than
access to different documents. A pre-generation selector chooses between a static,
one-call workflow and bounded ReAct using only target-independent question and
evidence features.

Our main evidence is a separately, prospectively frozen corrective comparison
on fresh development items. Under a shared final-answer contract, common
resource ceilings, and a verified retrieval-first ReAct treatment, Static
retained a macro advantage whose frozen 95\% interval excluded zero, while
ReAct supplied only five unique exact successes. An earlier five-dataset routing
study motivates the correction: its fallback routed too broadly and failed its
quality--cost criterion, but a trace audit exposed unequal answer and context
contracts. We therefore treat those earlier results as pilot evidence rather
than the basis for the central claim.

Our contribution is a feasibility test that precedes ordinary routing
optimization: expert complementarity must be established before router
optimization. When the expensive branch contributes few unique correct
answers, routing cannot materially improve the accuracy--cost frontier,
regardless of selector quality. Evaluation contracts can distort that measured
complementarity, so they must be harmonized before the test. This is an
auditable negative result for bounded workflows, not a universal claim against
agents.
