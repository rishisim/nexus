\section{Experimental Protocol}
\label{sec:protocol}

\paragraph{Evidence and fresh split.}
The main study uses 50 examples each from FinQA, TAT-QA, and ConvFinQA. Systems
see only table, text, or dialogue evidence supplied by the benchmarks; gold
answers and fields derived from targets are unavailable before Finish. The manifest excludes all
identifiers used by earlier studies or stopped freezes and all protected final
identifiers; ConvFinQA is also disjoint by dialogue. Final content was never
loaded, executed, or scored. The same 150 items and frozen order are used for
all tiers and both arms.

\paragraph{Capability ladder and action transport.}
The mandatory tiers are GPT-4o-mini (control), GPT-5.6 Luna, and GPT-5.6 Terra,
all through the same OpenRouter backend restricted to the OpenAI provider, with
fallbacks and provider data collection disabled. GPT-4o-mini omits an
unsupported reasoning field; Luna and Terra use
\texttt{reasoning\_effort=none}. Each turn makes exactly one strict tool call
containing \texttt{action}, \texttt{argument}, and \texttt{answer}; malformed
output or telemetry stops the study. Static permits Finish; ReAct must begin
with Search, observe evidence, and use at least two calls. Calls have one
attempt, an output ceiling of 384 tokens, prompt ceilings of 4,096 words and
8,192 bytes, and an evidence ceiling of 3,000 words.

The frozen schedule balances all six model orders across 25 items each and gives
each tier 75 items with Static first and 75 with ReAct first. Two earlier freezes stopped under fixed
transport rules; no partial outcomes were analyzed, and touched items were
excluded. Full provenance, configurations, audit code, and sanitized metric
pairs are in the anonymous offline artifact. The main run used 1,462 calls and
US\$0.948; cumulative spend before replication was US\$1.007 under a US\$20 cap.

\paragraph{Preregistered analysis.}
Quality is the unweighted macro average of FinQA exact match, official TAT-QA
F1 with scale inferred from the prediction, and ConvFinQA exact match. For each
tier we report a paired percentile bootstrap with 10,000 samples stratified by
dataset, the exact complementarity matrix and McNemar test, oracle headroom,
and efficiency. Interactions bootstrap differences between tier effects for
ReAct minus Static. Scoring began only after all three tiers completed.

Calls used a fixed request seed, but temperature and top $p$ were omitted and
provider defaults applied, so generation was not guaranteed to be deterministic.
After seeing the main result, we froze one post hoc replication on the same
manifest that changed only the seed. It completed all 900 episodes for
US\$0.951 (US\$1.959 cumulative). We report it as a stability check conditional
on the same sample, not an independent confirmation.

\paragraph{Supporting studies.}
The original Gemini study across five datasets compared five workflows and a
selector under unequal contracts. A later harmonized study with GPT-4o-mini on
150 separate fresh items shared contracts and verified that ReAct retrieved
before answering. These unpublished, non-concurrent experiments share the
research question and implementation lineage but not evaluated identifiers
with the main study. They are pilot and supporting evidence, respectively.
